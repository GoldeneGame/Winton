# Changelog — La Taverne

Les nouveautés de chaque version sont affichées dans le launcher avant la mise à jour.

## 1.0.0
- Première version publiée sur Winton.
- Les parties, images et réglages (config.json) sont maintenant rangés dans `%APPDATA%\LaTaverne` :
  une mise à jour ne peut plus les effacer. Ceux de l'ancien dossier `data\` sont recopiés automatiquement.
